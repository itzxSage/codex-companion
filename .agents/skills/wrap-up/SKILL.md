# Wrap Up

Summarize completed work, artifact locations, verification performed, and any unresolved choice. Distinguish planned actions from executed actions. Include no credentials or full transcripts. Write durable notes or task updates only if the owner asked to save them. Use companion.py commands for supported updates; for requested corrections inspect only the relevant records and make a minimal local edit preserving valid JSON. Recommend one clear next step and stop. Do not start another model session, background process, monitor, or scheduled task. A handoff should normally be under 150 words; do not sacrifice a material blocker to meet that target.
